# Development of a Codon Table Generator

## Project Description
This project develops a Python-based codon table generator to translate DNA and RNA sequences into their corresponding amino acids using the standard genetic code.

## Features
- Codon table containing codons and their corresponding amino acids.
- DNA and RNA sequence validation.
- Division of sequences into codons.
- Translation of codons into amino acids.
- Identification of start and stop codons.
- Handling of incomplete codons.
- Codon frequency counting.
- GC content calculation.
- Comparison with a reference codon table from GitHub.

## Technologies Used
- Python
- Jupyter Notebook
- Git and GitHub

## How to Run
1. Download or clone this repository.
2. Open the Jupyter Notebook.
3. Run the cells in order.
4. Enter a DNA or RNA sequence when prompted.
